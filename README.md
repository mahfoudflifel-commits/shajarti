# شجرتي — شركة أرض البركة للإنتاج الزراعي

موقع عربي قابل للنشر: دخول برقم الهاتف (Supabase OTP)، حساب العائلة، طلب ربط شجرة عبر رمز QR، اعتماد الغرس بواسطة الموظف، شهادة PDF، سجل متابعة الأشجار، ولوحة إدارة أساسية.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. أنشئ مشروعًا في Supabase ثم نفّذ محتوى `schema.sql` في SQL Editor.
4. فعّل Phone Auth واضبط مزود رسائل SMS في Supabase. اختبر الإرسال لأرقام ليبيا قبل الإطلاق.
5. انسخ `.env.example` إلى `.env` واملأ رابط Supabase ومفتاح publishable/anon **العام فقط**. لا تضع service_role في الواجهة.
6. نفّذ `npm run dev` وافتح الرابط المحلي.
7. سجّل الدخول أولًا بحساب مدير ثم خذ UUID الخاص به من Authentication > Users، ونفّذ أمر إدخاله في `staff` الموجود أسفل schema.sql.
8. في Vercel اربط مستودع المشروع، وأضف المتغيرين VITE_SUPABASE_URL وVITE_SUPABASE_ANON_KEY، ثم Deploy. أضف الدومين من إعدادات المشروع.
9. اطبع QR لكل شجرة بعنوان `https://YOUR-DOMAIN/?tree=TT-2026-0001`، واطبع الرقم نفسه على البطاقة.

## ما هو جاهز وما يحتاج استكمالًا
- الواجهة وقاعدة البيانات وسياسات الوصول الأساسية وطلب الربط والموافقة والشهادات PDF قابلة للتشغيل بعد التهيئة.
- رفع الصور من لوحة الإدارة غير مطبق؛ يمكن إضافة سجلات `tree_updates` عبر Supabase Dashboard حاليًا، مع روابط صور موثوقة.
- مسح QR يتم عبر كاميرا الهاتف الأصلية (فتح رابط QR)، وليس ماسحًا داخل الموقع.
- عند فتح QR قبل تسجيل الدخول، احتفظ بالرابط وأعد فتحه بعد تسجيل الدخول؛ توجيه تلقائي لاحق يمكن إضافته.
- لا يوجد وضع Offline أو إشعارات واتساب أو خريطة تفاعلية أو تقارير متقدمة في هذه النسخة.
- شهادة PDF تُنتج من لقطة شاشة للصفحة وقد تحتاج تحسين تنسيق قبل الطباعة الرسمية.
- راجع سياسة الخصوصية، الموافقة، الاحتفاظ بالبيانات، حماية الصور، اختبار صلاحيات RLS، واختبارات الأداء قبل الاستخدام العام.
- التأكيد الإداري يعني إثبات الغرس من الموظف؛ لا تُصدر شهادة حتى يعتمد الطلب.
